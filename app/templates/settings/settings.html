Connection Info

To connect other devices (Teacher/Principal tablets or phones) on the Local Wi-Fi Network:

  1. Ensure all devices are connected to the same Wi-Fi network.
  2. Open a browser on the client device.
  3. Enter: http://{{ settings.get('server_ip', '0.0.0.0') }}:{{ settings.get('server_port', '5000') }}
  4. Login with your credentials.
Tip: To find the server's IP, run ipconfig (Windows) or ifconfig (Linux) on the server machine. Use the IPv4 address from the Wi-Fi adapter.

  • Scanner acts as a keyboard input device.
